# pair-wise-yf-48 建筑设计竞赛匿名评审

源提示词摘要：主办方设置评分维度、权重和提交规则，评委在匿名状态下独立查看方案、打分、填写意见、声明利益冲突和保存草稿；系统提供提交进度、异常分处理、结果锁定与并列排名规则。

## 技术栈

Vue3、TypeScript、Vite、Naive UI、Pinia、Vue Router、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62013

## 回避与匿名机制

- **两套数据**：`Scheme` 只含匿名编号与方案内容（评委读路径）；`SchemeIdentity` 单独保存作者姓名、申报单位与版本号，仅主办方可读。评委侧只能拿到 `maskedIdentity()` 脱敏视图。
- **自动回避**：`recusalSet` 按评委申报单位相同或姓名出现在作者名单中实时计算；命中回避的方案对评委封死（不展示内容、不能评分），评委无需也无法看到作者信息。
- **变更即重算**：作者/单位或评委申报单位变更时身份版本递增，回避集合立即重算，受影响的已提交评分保留审计记录但退出「有效评委数」（`isScoreActive=false`），并在审计日志留痕。
- **越权拒绝**：评委读取身份库、主办方评分、评委退回/改动他人评分均抛 `AccessDeniedError` 并写入 denied 审计；评分视图提供越权探测按钮用于演示。
- **锁定纪律**：锁定前主办方只看到「应参评/已提交」进度，看不到任何分值；锁定时排名生成快照固化，之后评分不可改、身份库冻结，任何更正只登记「待更正记录」，原排名保留。
